# tonypham-prototypes-deploy

A place to keep the demos I make. Each demo lives on its own `demo/<name>` branch with an open pull request, and gets a public `https://….pages.dev` link through Cloudflare Pages.

Status: planned, not built yet. See [the plan](docs/plan/PLAN.md).

## Layout

```text
.
├── demos/             # one folder per demo
├── scripts/           # stage and scaffold helpers
├── .github/workflows/ # preview and cleanup automation
└── docs/
    ├── plan/          # current plan
    ├── prompts/       # build prompt for a coding agent
    └── archive/       # retired plans
```
