Send the sizes that sell

An international fashion brand sends every store the same size mix. This demo allocates by each store's own size curve instead. From the same stock targets, it loses fewer sales and ends the season with less leftover stock.

1 · ProblemWho decides, and what goes wrong?

The head of merchandising planning decides each Monday which sizes go to which stores for the next weeks. Today one chain-wide size mix goes everywhere. Tokyo runs out of S while Chicago runs out of XL, and both stores end the season with sizes nobody bought.

2 · DesignHow does the data flow?

  1. Source feedsStore sales and stock snapshots, daily
  2. StagingClean, deduplicate, re-read late store sales
  3. MartOne row per store × style-colour-size × day
  4. ForecastWeekly units per style × store
  5. Size curveOne per store, stockouts corrected
  6. AllocationUnits per size per store, each cycle

Metrics, defined once

Sell-through
Units sold ÷ units received.
Lost sales
Demand in weeks when the size was out of stock, minus what sold in those weeks.
Leftover
Units still in store at season end, the stock that gets marked down.

Scale of this demo

40 stores × 60 styles × 6 sizes × 26 weeks = 374,400 rows per season

The demo runs the mart at weekly grain so it fits in a browser. Production scale would be about 5,000 styles across 200 stores, at daily grain.

3 · Hard decisionForecast each SKU, or each style and store?

Chosen: style × store, then split by size curve

Each style-store sells enough to forecast. The size split comes from the store's own history, pooled across all styles, so it is stable.

Rejected: one forecast per SKU

A SKU (stock-keeping unit) is one style-colour-size. Most SKUs sell a few units a week or less, so their forecasts are mostly noise.

4 · ProofDoes it beat last season's size mix?

Both methods replay a held-out season with the same demand and the same stock target per style and store. Only the split across sizes differs. Stock is topped up each cycle to replace what sold, so the method that sells more also receives more.

Trap handled: zero sales on a sold-out week is not zero demand

When a size sells out, its sales stop. Counting those weeks as low demand makes the sizes that ran out look less popular, so you send even fewer next time. The correction estimates demand from how fast each size sold while it had stock. If a size never had stock, it borrows that store's ratio to the other sizes. Turn the checkbox off to watch lost sales rise.
